# 🔐 CyberGuard - Password Strength Analyzer

CyberGuard is a Java-based desktop application that helps users evaluate the strength of their passwords and generate secure passwords. This project was built to demonstrate cybersecurity concepts such as password security, input validation, and secure password creation using Java Swing.

---

## 🚀 Features

✅ Password Strength Analysis

✅ Password Strength Score (0-5)

✅ Secure Password Generator

✅ Security Recommendations

✅ Color-Coded Strength Indicators

✅ User-Friendly Java Swing Interface

---

## 🛠️ Technologies Used

- Java
- Java Swing
- Regular Expressions (Regex)
- Object-Oriented Programming (OOP)

---

## 📋 How It Works

The application evaluates passwords based on the following criteria:

- Minimum length of 8 characters
- Contains uppercase letters
- Contains lowercase letters
- Contains numbers
- Contains special characters

Based on these checks, the password is classified as:

| Score | Strength |
|---------|---------|
| 0 - 2 | Weak |
| 3 - 4 | Medium |
| 5 | Strong |

---

## 🔑 Password Generator

CyberGuard can automatically generate strong passwords containing:

- Uppercase letters
- Lowercase letters
- Numbers
- Special characters

This helps users create more secure passwords for their accounts.
